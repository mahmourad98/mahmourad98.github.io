# personal-portfolio

One-page resume and app portfolio for Mahmut Murat, live at [mahmourad.com](https://mahmourad.com).

Plain HTML/CSS, no build step: `index.html` holds all content, `css/style.css` the styles.
Open `index.html` in a browser to preview. Pushing to `main` deploys via GitHub Pages (custom domain set in `CNAME`).
